# LOOK-Configurator

Пошаговый мастер настройки ЛООК (Windows 11, PowerShell 5.1, без внешних зависимостей).

## Запуск
`Start.cmd` (самоповышение до администратора). Меню: пройти мастер / выбрать шаг / проверить все шаги.
В каждом шаге: **1 Применить, 2 Проверить, 3 Пропустить, 4 Откатить, 0 Выйти**.
Выбор цифрами, чтобы не зависеть от раскладки клавиатуры.

## Структура
```
Start.cmd                 запуск
Start-Configurator.ps1    точка входа: права администратора, загрузка lib\, главное меню
lib\Common.ps1            вывод, лог, состояние, Invoke-Native, проверки
lib\Wizard.ps1            ядро: загрузка шагов, Apply/Verify/Rollback, меню
lib\*.ps1                 помощники по областям (Power.ps1, далее Registry, Services, Lgpo, ...)
steps\<id>.ps1            по одному файлу на шаг
config\sequence.json      порядок шагов (меняйте порядок/добавляйте/убирайте здесь)
config\profile.json       параметры (значения для шагов, данные устройства)
state\                    (в .gitignore) state.json, резервные значения для отката, логи
```

## Как добавить шаг
1. Создать `steps\<id>.ps1`, возвращающий хэштаблицу:
   `Id` (= имени файла), `Title`, `Apply`, `Verify` (обязательно); `Backup`, `Rollback`,
   `Reference`, `Description`, `Reversible` (необязательно, по умолчанию `$true`).
2. Добавить `<id>` в `config\sequence.json` в нужное место.
3. Параметры шага положить в `profile.json` -> `steps` -> `<id>`.

Блоки получают `$ctx` (`Id`, `Params`, `Profile`, `Step`):
- `Backup { param($ctx) }` возвращает хэштаблицу исходных значений. Вызывается один раз до первого Apply.
- `Apply { param($ctx) }` вносит изменения.
- `Verify { param($ctx) }` возвращает набор `New-Check`; по нему строится отчёт соответствия.
- `Rollback { param($ctx, $backup) }` возвращает исходное состояние.

Блоки не должны писать ничего в конвейер (кроме Backup и Verify): для сообщений используйте `Write-Ui` / `Write-Log`.
Внешние команды запускайте через `Invoke-Native` (бросает исключение при ненулевом коде возврата).
Необратимые шаги (BitLocker, разметка) помечайте `Reversible = $false`: мастер запросит подтверждение.

Данные шага (список параметров и т.п.) храните в самом описании шага (`$ctx.Step.<поле>`), а не в переменных файла:
после загрузки файла его локальные переменные недоступны блокам.

## Кодировка
Все `.ps1` в UTF-8 **с BOM** (иначе PowerShell 5.1 ломает кириллицу). Не пересохраняйте без BOM.
